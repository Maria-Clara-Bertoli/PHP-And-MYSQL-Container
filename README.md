# 🚢 Container Development Using PHP with MySQL Database Connection

This repository contains the implementation of a **containerized application** that uses the **PHP** programming language to communicate with a **MySQL** database.

🐳 The application is designed to be easily executed within a **Docker** environment.

---

## ⚙️ Features

- 🚀 Development of a **container** to run the PHP application  
- 🔗 **Connection to a MySQL database** for data querying  
- 🐳 Use of **Docker** to simplify environment setup and execution  

---

## 🛠️ Technologies Used

- PHP 🐘  
- MySQL 🗄️  
- Docker 🐳
